Сюда положите картинку или гифку для страницы 404.
Например: error.gif, cat.png, 404.webp

Затем откройте src/data/notFoundMedia.js и укажите путь:
  src: '/404/error.gif'

Пока путь пустой — на странице показывается пунктирная заглушка.

Put an image or a GIF for the 404 page here.
For example: error.gif, cat.png, 404.webp

Then open src/data/notFoundMedia.js and set the path:
  src: '/404/error.gif'

While the path is empty, a dashed placeholder is shown instead.
