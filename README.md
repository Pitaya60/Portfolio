# Портфолио — Абдулла Камилла

React + Vite. Статический сайт, разворачивается на Vercel одной кнопкой.

## Запуск

```bash
npm install
npm run dev      # локально, http://localhost:5173
npm run build    # сборка в dist/
```

## Что заполнить в первую очередь

### 1. Ссылки на соцсети — `src/data/contacts.js`

Сейчас там заглушки. Замените:

| Поле | Что вписать |
|---|---|
| `telegram` | ссылка на ваш личный аккаунт, например `https://t.me/kamilla` |
| `telegramLabel` | как показывать: `@kamilla` |
| `telegramChannel` | ссылка на канал/группу |
| `telegramChannelLabel` | `@channel` |
| `linkedin` | ссылка на профиль |

Эти значения подставляются в шапку, подвал и модальное окно «Написать» —
править нужно только один файл.

### 2. Резюме — два файла

| Язык | Файл |
|---|---|
| Русский | `public/resume.pdf` |
| Английский | `public/resume-en.pdf` |

Ссылка «Резюме» / «Resume» в шапке, подвале и на странице «Обо мне»
сама подставляет нужный файл в зависимости от выбранного языка.

Сейчас в `public/resume-en.pdf` лежит копия русского резюме как заглушка —
просто замените этот файл английской версией. Пути при необходимости
меняются в `src/data/contacts.js` → `resume: { ru, en }`.

### 3. Фото

На странице «Обо мне» стоит заглушка. Замените блок `.about-photo`
в `src/pages/About.jsx` на `<img src="/photo.jpg" alt="Абдулла Камилла" />`,
а сам файл положите в `public/`.

### 4. Картинка или гифка на странице 404

1. Положите файл в `public/404/` (например `public/404/error.gif`).
2. Откройте `src/data/notFoundMedia.js` и укажите путь: `src: '/404/error.gif'`.
3. Там же настраиваются пропорции (`ratio`) и максимальная ширина (`maxWidth`).

Пока путь пустой или файл не найден — на его месте пунктирная заглушка
нужного размера, страница не ломается. Форматы: gif, png, jpg, svg, webp.

### 5. Картинки кейсов

В `src/data/caseStudies.ru.js` и `src/data/caseStudies.en.js` у каждого кейса есть:

- `coverImage` — обложка для карточки на главной (16:9, ~1200×675)
- `images.cover[0]` — большая обложка внутри кейса (~1400×900)

Пока они пустые, показываются заглушки с указанием нужного размера.
Файлы кладите в `public/cases/` и указывайте путь как `/cases/qmed-cover.png`.
Пути к картинкам в русском и английском файлах должны совпадать —
меняются только тексты.

## Два языка: RU / EN

Переключатель RU/EN стоит в шапке: на десктопе — рядом с кнопкой «Написать»,
на мобильных — слева от бургер-меню. Выбор сохраняется в браузере
(`localStorage`), при первом заходе язык определяется по настройкам браузера.
Вместе с языком меняются `<html lang>`, заголовок вкладки и og-описание.

Где что лежит:

| Что переводим | Файл |
|---|---|
| Кнопки, меню, подписи интерфейса | `src/i18n/ui.js` |
| Имя, роль, город, время ответа, пути к резюме | `src/data/contacts.js` |
| Страница «Обо мне»: опыт, образование, навыки, языки | `src/data/about.js` |
| Кейсы (русские) | `src/data/caseStudies.ru.js` |
| Кейсы (английские) | `src/data/caseStudies.en.js` |
| Тексты на странице 404 | `src/i18n/ui.js` → `notFound` |

Как добавить новый кейс: добавьте объект в **оба** файла кейсов с одинаковым
`slug` и в одном и том же порядке. Если строки в `ui.js` для английского
не окажется — подставится русская, сайт не сломается.

## Структура

```
src/
  components/    Nav, Footer, CaseCard, ContactModal, ImageSlot
  context/       ContactContext — состояние модального окна
  data/          contacts.js (контакты), caseStudies.js (кейсы)
  pages/         Home, About, CaseStudy, CustomCaseStudy, NotFound
  styles/        global.css — токены: цвета, отступы, шрифты, кнопки
```

Все размеры и цвета заданы переменными в `src/styles/global.css`.
Чтобы поменять акцентный цвет по всему сайту, достаточно править `--accent`.

## Типы блоков в кейсах

Кейсы собираются из блоков в `customSections`. Доступные `type`:

`text`, `cards`, `twoColumn`, `checklist`, `pills`, `combo`, `imageText`,
`timeline`, `screens`, `compare`, `table`, `cjm`, `note`, `conclusion`.

Каждый блок автоматически получает порядковый номер и заголовок с линией —
структура кейса читается как отчёт.
